# 0007. UUIDv7 for every entity id

- Status: Accepted
- Date: 2026-10-13

## Context
Thousands of nodes generate records offline that must merge at HQ without key collisions.

## Decision
All ids are RFC 9562 UUIDv7 generated by `UuidV7` on the node: coordination-free and time-ordered
(append-friendly B-tree inserts at HQ).

## Consequences
`ArchitectureTest.idsAreUuidV7` forbids `UUID.randomUUID()`; `MigrationLockTest` forbids
SERIAL/IDENTITY/SEQUENCE keys.
